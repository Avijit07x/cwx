# Task list

Granular tasks derived from the brief (`docs/design/BRIEF.md`, git-ignored) and the plan ([PLAN.md](PLAN.md)). A task is marked ✅ only after its verification step has been run and passed; the "Verified by" column records how.

Legend: ✅ verified · 🚧 in progress · ⬜ not started · ⚠️ done with a caveat · ❌ failed verification · 👤 needs you

Roles: **Me** = main session (architecture, foundation, integration). **Build agents** own disjoint folders (see [CONTRACTS.md](CONTRACTS.md)). Verification is done by **teams of 2–3 agents that discuss** (QA, code quality, code review, design doc, model optimisation); reviewers never fix their own findings.
